## 0. 摘要

每个带内轮站恰好一个**动态轮端刚体**（SBW 内部名 `wheelBody`）：

1. 承担轮端安装、轮形碰撞、轮质量与惯量；
2. **没有独立轮面自转自由度**（相对安装机构不自转）；
3. run 直接约束到该刚体，**不创建第二个物理滚动子体**；
4. 可见轮面自转只为渲染服务，不进入物理安装 frame。

同时撤回两句不成立的旧表述：

- “自转轮 frame 一定会带 run 公转”：**不成立**。正确的转动副能隔离相对转动，
  现有证据不能支持“必然公转”。不采用物理 spin 的理由是已恢复的 MCSP 带内轮分支
  与接触驱动方式，以及避免无必要的质量与自由度，而不是公转恐惧。
- “非自转 carrier”与“安装框架与滚动部件分离”是两个并列选项：**不是**。
  后者的一种实现就是前者；“分离”的对象是**物理轮端状态与可见轮面自转**。

## 1. MCSP 证据与适用边界

| 位置 | 已确认行为 |
|---|---|
| `quistaphys-java/src/quista/phys/gear/PhysGearBelt.java:24` | belt 的 `driveSlot` 必须非负 |
| `quistaphys-java/src/quista/phys/gear/PhysGearSpec.java:115` | belt member 使用 belt 的 `driveSlot`，轮自己的 FREE 被覆盖 |
| `quistaphys-java/src/quista/phys/gear/PhysGear.java:657` | `free = slot < 0`，带内轮因此走 `free == false` |
| 同文件 `:659`、`:680`、`:681` | 带内轮不创建独立 `hub/spin` 层 |
| 同文件 `:671`、`:714` | 无转向的带内轮经悬挂或固定副直接连接 carrier；SLIDER 无独立滚动自由度 |

| `mcs-java/quista/mcs/platform/PlatformGearDraw.java:259` | 可见轮自转与 belt phase 按速度积分，不要求存在物理 spin body |

**边界：** MCSP 也支持 ARM 悬挂与转向，那里的 carrier 可随摆臂/转向机构改变姿态，
不能概括成“所有 carrier 相对 hull 永不旋转”。本决定只冻结 SBW 首版目标，
且不导入 MCSP 的悬挂枚举或 `carrier/hub/knuckle/spin` 资源 schema。

## 2. 刚体结构与语义

```text
chassis（车体）
 ├─ wheelBody：Support      —— 平移悬挂导向 + 双向弹簧/阻尼
 ├─ wheelBody：DriveGuide   —— 固定安装约束
 └─ wheelBody：IdlerGuide   —— 张紧轴导向 + 预载/阻尼

每个 run（相邻轮对，含 last→first）：
 wheelBody[i]    ── 端1：轮心转动副 ──────────  run[i]
 wheelBody[i+1]  ── 端2：只锁 run 法向平移 ────  run[i]

可见轮面：消费机构状态 + 带速积分自转，不是第二个物理刚体。
```

“不自转”只表示**相对安装机构没有独立轮面滚动自由度**，不代表世界角速度为零：
车体转动时轮端随机构转动；不得每步清零角速度或强制写回姿态。

## 3. 轮端自由度（全部相对安装框架，不使用世界坐标锁轴）

| 轮角色 | 平移自由度 | 旋转自由度 | 施力 |
|---|---|---|---|
| `Support` | 仅悬挂轴，范围 `[-TravelDown, +TravelUp]` | 三轴锁定 | 复用双向 `PhysicsSuspensionRow`（含 bump stop 与对称 `MaxForce`） |
| `DriveGuide` | 三轴锁定 | 三轴锁定 | 不施加轮自转电机扭矩；驱动走接触面运动 |
| `IdlerGuide`（有张紧器） | 仅声明的张紧轴，范围 `[-Travel, +Travel]` | 三轴锁定 | 张紧预载 + 速度阻尼 |
| `ReturnRoller`（后续车型） | 固定安装；不得静默套负重轮悬挂 | 三轴锁定 | 无悬挂力 |

框架定义：

- 悬挂导向：`X = 轮轴`、`Y = 悬挂方向`、`Z = X × Y`，右手系。
- 张紧导向：以张紧方向作为该框架的 Y，轴为 X。
- 编译器验证正交与轴对齐；不静默投影倾斜输入。

`PhysicsJoints.guidedWheelAxle()` 放行轮轴旋转，**不用于本版带内轮安装**；
保留它服务其他自由滚动机构。安装约束由 SBW 适配层用通用 `New6Dof` 显式构造。

## 4. 两端约束语义（明确到 frame 级别）

| run 连接 | 锚点与 frame | 自由度 |
|---|---|---|
| 端 1 | 两侧锚点在初始第一轮轮心重合；关节 X 沿轮轴 | 锁三平移、锁 ANG_Y/Z、**真正放行 ANG_X**（自由设置，不用巨大有限区间冒充） |
| 端 2 | 初始第二轮轮心分别变换到 run 局部坐标与第二轮局部坐标 | **只锁 run 法向平移**；其余两平移与三旋转全部自由 |

端 2 采用 `bodyA = run`、`bodyB = 第二轮`，使约束法向随 run 旋转，
而不是固定成世界 Y。该映射是**目标**，不是已证等价；native mask `0x04`
只证明“只锁一个平移”的语义等级。

两个端点都不依赖刚体 X 轴猜测：所有关节保存两侧局部锚点、局部旋转与 body ID。

## 5. 质量预算（已选定方案 A）

之前指南 §5 的表 B 推导有误，**不得按原样实施**。正确关系：

- MCSP 对带内轮保留 `0.6 × m` 在轮端体上，每个 run 取 `0.2 × (m_i + m_next)`；
- 对闭环轮序，`Σ 0.2(m_i + m_{i+1}) = 0.4 × Σm`；
- 所以 `0.6` 与 `0.4` 正好守恒拆分**轮质量**，不是“再额外加 run 质量”。

**决定（2026-10-23）：采用方案 A。**

- 轮端刚体保留 authored `Mass`（99A：6 200 kg/侧）。
- run 总预算 = 旧鞋预算 `LinkMass × LinkCount`（99A：1 422 kg/侧），
  按每对相邻轮的合成质量比例分配，**逐侧精确守恒**。
- 因此整车总质量不变（55 000 kg），车体仍为 39 756 kg，可用于把拓扑变更
  与质量变更隔离测量。
- run 质量公式是**通用编译规则**，不是 99A 专用常量；99A 的具体数值只是
  该规则作用在现有数据上的结果。
- A 是诊断基线，不自动成为后续车型的默认质量策略；B/C 的评估留到 B2 承载
  通过之后。

99A 每侧轮质量 6 200 kg 时：

| 方案 | 轮端体 | run 合计 | 运行机构/侧 | 车体（总 55 000） | 说明 |
|---|---|---|---|---|---|
| **A. 沿用现预算（已采用）** | 6 200 | 1 422（鞋预算转入） | 7 622 | 39 756 | 总量不变；run 按轮对合成质量分配 |
| B. MCSP 守恒拆分 | 0.6×6200=3 720 | 0.4×6200=2 480 | 6 200 | 42 600 | 鞋不再模拟，其 1 422/侧归车体；留待 B2 后评估 |
| C. 轮质量重审后再套公式 | 待定 | 待定 | 待定 | 待定 | 改动最大，需重审轮惯量与悬挂载荷 |

**禁止**把 MCSP 质量公式**叠加**在现有鞋质量之上；A 的实现方式是替换，不是相加。

## 7. 驱动与渲染

- 驱动：真实接触面上的切向运动目标；显式三态 `DRIVE / BRAKE / COAST`；
  牵引读数 = 冲量 ÷ 时间步（N），按实际源安装体归属，不平分、不重复累计。
- Bullet 求解前接触修改的时序未证明前，**不默认回退到轮电机或直接推车体**。
- 渲染：可见轮中心消费权威悬挂/张紧状态；轮面自转按带速积分；
  该角度不进入物理 frame；run 碰撞体不因轮面动画或地形每步重建。
- 可见链节计数初始化固定（`max(1, ceil(L_rest/pitch − 0.001))`），
  间距按当前长度分配；模板纵向长度 `0.23307 m` 是有来源的候选节距，
  规则确认前不写死。

## 8. 装配顺序与验证门

1. **纯数据**：编译并验证质量、框架、轮序、连接关系；错误规格不得进入运行时。
   → **已通过**：`TrackedRunGeometryTest` 13 项 + 既有 71 项，共 84 项 0 失败。
2. **单轮站**：悬挂压缩/下垂恢复、张紧方向与限位、相对旋转锁定、
   车体整体旋转后框架仍正确。
3. **两轮两 run**：端 1 可相对转动；端 2 切向可滑、法向受限；
   抬升轮端后 run 跟随且局部盒形不变；把端 2 做成三平移全锁时测试必须失败。
4. **完整单侧**：装配探针比较旋转、连接、frames、限位、碰撞过滤与重力设置；
   整机构外力平衡不得重复累计接触力/悬挂力/约束力。
5. **双车侧与生产接线**：通过后再谈 S2；阈值先采集观测，再由用户确认。
